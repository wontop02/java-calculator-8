# 🖥️ 우테코 프리코스 1주차 - 문자열 덧셈 계산기
- 기능 요구 사항에 기재되지 않은, 스스로 판단한 부분은 **볼드체** 사용
## 📖 프로젝트 개요
- 사용자가 입력한 문자열에서 숫자를 추출해 더하는 계산기
- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우, 구분자를 기준으로 분리한 각 숫자의 합 반환
    - 예: "" => 0, "1,2" -> 3, "1,2:3" => 6
- 앞의 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자 지정 가능
    - 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용
    - 예: "//;\n1;2;3"과 같이 입력했을 경우 커스텀 구분자는 세미콜론(;)
    - **커스텀 구분자를 지정할 경우 기본 구분자는 적용하지 않음**
    - **커스텀 구분자는 길이 1 이상의 문자열이어야 함(필수 입력)**
    - **커스텀 구분자에는 "\n"이 포함될 수 없음**
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 종료

## ⌨️ 입출력 요구 사항

#### 입력
- 구분자와 양수로 구성된 문자열
    - 입력 숫자가 음수일 경우 에러 발생
    - 문자열이 비어 있지 않을 때, 숫자나 구분자 또는 "//"로 시작되지 않는 경우 에러 발생
    - 문자열이 "//"로 시작했으나 뒤쪽에 "\n"이 존재하지 않는 경우 에러 발생
    - **기본 구분자 혹은 커스텀 구분자를 제외한 문자가 있는 경우 에러 발생(공백 포함)**
    - **커스텀 구분자의 길이가 1보다 작은 경우 에러 발생**
    - **커스텀 구분자에 "\n"이 포함되어 있는 경우 에러 발생**

#### 출력
- 덧셈 결과

#### 실행 결과 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

## ✅ 구현 기능 목록

### 사용자 입력
- [x] 사용자에게 입력값 요청
    - [x] `camp.nextstep.edu.missionutils.Console`의 `readLine()` 활용
- [x] 문자열 검증: 잘못된 값일 경우 `IllegalArgumentException` 발생
    - [x] 문자열이 비어 있지 않을 때, 숫자나 구분자 또는 "//"로 시작되지 않는 경우
    - [x] 문자열이 "//"로 시작했으나 뒤쪽에 "\n"이 존재하지 않는 경우

### 커스텀 구분자 지정
- [x] 문자열이 "//"로 시작하는 경우 "//"와 "\n" 사이의 문자를 커스텀 구분자로 지정
- [x] 문자열 검증: 잘못된 값일 경우 `IllegalArgumentException` 발생
    - [x] 커스텀 구분자가 입력되지 않은 경우
    - [x] 커스텀 구분자에 "\n"이 포함되어 있는 경우

### 숫자 추출
- [ ] 구분자에 따라 문자열에서 숫자 추출
    - [ ] 숫자가 없을 경우, 0 추출 
- [ ] 문자열 검증: 잘못된 값일 경우 `IllegalArgumentException` 발생
    - [ ] 음수가 존재하는 경우(커스텀 구분자가 "-"가 아닌데 "-" 문자가 있을 경우)
    - [ ] 기본 구분자 혹은 커스텀 구분자를 제외한 문자가 있을 경우(공백 포함)

### 숫자 더하기
- [ ] 주어진 숫자를 더해 결과값 반환

### 콘솔 출력
- [ ] 출력 요구사항에 따라 콘솔에 출력
  - [ ] 프로그램 실행 시 "덧셈할 문자열을 입력해 주세요." 출력
  - [ ] 더하기 결과가 나오면 "결과 : " + 결과값 출력
